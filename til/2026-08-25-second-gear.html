Critical / AI Security Stealing Reasoning Traces from Proprietary LLM APIs

Pre-read: Opaque agent state is becoming part of the software supply chain: logs, resumable sessions, MCP tool calls, and cloud sandboxes now move between users and systems. Security teams already scan prompts, outputs, secrets, and repos, but encrypted model-side state has been treated more like provider plumbing than an inspectable artifact. This paper clarifies why that assumption is weak.

Summary: The paper says major providers return concealed chain-of-thought state to clients as encrypted blocks so conversations can remain stateless server-side. The vulnerability is contextual binding: blocks can be replayed across sessions, users, and model variants inside a provider ecosystem. The researchers use weaker sibling models as fuzzy decoders, then report four attack paths: trace extraction for distillation, private-data recovery from public agent logs, hazardous reasoning leakage, and invisible prompt injection through planted blocks. Their public-scan result is the most operationally important number: 315,320 decoded blocks from 6,708 trajectories produced 367 PII artifacts and 182 credentials. The mitigation frame is crisp: authenticate not only the encrypted content, but also the user, session, model, and predecessor context that make the block legitimate.

Critical / Agentic Software Why Ramp built its own in-house coding agent, Inspect

Pre-read: Enterprise coding agents are becoming internal platforms, not just IDE features. The hard part is less model access than giving agents safe, fast, auditable access to code, telemetry, feature flags, databases, browsers, and review workflows. Ramp's case is useful because it shows what happens when the harness becomes company infrastructure.

Summary: Pragmatic Engineer reports that Ramp's Inspect runs coding agents in remote sandboxes with internal integrations and verification loops. Ramp says 75% of merged PRs now come from Inspect sessions, up from roughly 60% two months after the background-agent launch; the Inspect repo itself is around 90% Inspect-authored PRs. The stack includes React/Vite, Cloudflare Durable Objects, SQLite, Cloudflare Agents SDK, Modal sandboxes, OpenCode, VS Code Server, Chromium, and local services such as Postgres, Redis, RabbitMQ, and Temporal. The strongest product lesson is that remote, shared, observable agent sessions let Ramp build bugfixing, code review, on-call, data-analysis, and frontend QA agents on the same substrate. Buy-versus-build looks different when the agent needs privileged company context and must prove its work.

Ideation

Ideation

Idea 1 State Ledger for Agent Runs

Sell a security layer for enterprise agent platforms that treats every hidden reasoning block, context bundle, tool transcript, and sandbox snapshot as signed state with lineage, expiry, replay rules, and redaction status. The first buyer is the platform/security team already running internal agents with broad code, data, and production access; they need to know which agent state can be reused, shared, logged, resumed, or destroyed before a private transcript becomes an executable liability.

Source Signals

  • Stealing Reasoning Traces from Proprietary LLM APIs
    The paper shows why encrypted hidden state should be handled like sensitive executable material, not harmless metadata.
  • Why Ramp built its own in-house coding agent, Inspect
    Ramp-style internal agent platforms are becoming privileged development environments with deep integrations and persistent sessions.
  • AI-powered design reviews for hardware
    DRCY is a useful adjacent signal: high-liability agent reviews only work when findings are grounded, inspectable, and auditable.
  • Agentic AI security
    Teleport and others already cover agent identity, secrets, and access control, so the sharper wedge is state provenance and replay governance.

Why Now

Internal agents are shifting from local copilots to remote, long-running operators with access to code, data, CI, observability, MCP servers, and production-like sandboxes. Current security products mostly watch prompts, outputs, tools, and secrets. The new primitive is agent state: portable context that can resume work, leak private reasoning, or carry invisible instructions even when the visible transcript looks clean.

First Wedge

A proxy and SDK for coding-agent platforms that fingerprints every model state artifact and run snapshot, strips provider-specific hidden-state blocks from exported logs, binds resumable state to user/org/session policy, and blocks replay into unapproved models or tenants. Start with enterprise coding-agent teams because they already have logs, sandboxes, SOC2 pressure, and a clear incident path.

Commercial Model

Sell to security engineering or internal developer-platform teams at companies building Ramp-like agent systems: base platform fee plus usage pricing by agent session or retained state bundle. Budget exists because these agents touch source code, production diagnostics, customer data, and credentials, and the alternative is banning useful logging/resume workflows.

Defensibility

The product compounds through integrations with agent harnesses, CI systems, log pipelines, model providers, and enterprise identity policy. Over time it owns the map of which state artifacts created which actions, which redactions were applied, and which replay policies prevented unsafe reuse. Incumbent DLP and identity tools can add agent features, but they do not naturally model hidden model state as a first-class object with lineage and replay semantics.

Technical Risk

The hard part is normalizing opaque state from different model providers and harnesses without breaking legitimate resume, fork, and compaction workflows. The system must detect sensitive state without needing to decrypt provider internals, preserve forensic value, and avoid becoming a brittle wrapper around changing API formats.

Market Expansion

After coding agents, the same ledger extends to data-analysis agents, incident-response agents, legal-review agents, and hardware/design-review agents where a retained context bundle can affect regulated decisions. The broader market is governance for autonomous work state, not just AI chat logs.

Self-Critique

This could be a feature inside agent runtimes, identity platforms, or model-provider APIs if customers frame the problem as narrow security hygiene. It only becomes a company if enterprises standardize on multiple agent harnesses and need a neutral control plane for state portability, retention, evidence, and replay across vendors.

Next Experiment

In two weeks, build a shim for OpenAI/Anthropic/Gemini-style agent logs plus one open-source coding harness. Scan public and private test transcripts for hidden-state artifacts, produce a lineage report, and show a security team three blocked replay/export cases they cannot express cleanly in existing DLP, SIEM, or IAM policy.
